# 2026.11.18 · 公开在线版

[打开最新版会议搭子](https://meeting-companion-kechangyuan3.happymorel8.chatgpt.site/)。直接分享此链接即可查看网页，不需要先在 GitHub 配置 Pages。

## 当前功能

- 实时语音：MOSS-Live 1.0 或讯飞星火超拟人交互；支持持续收音、中文字幕和语音回答。
- 会中问答：Nex N2.6，可带上当前会议文字，梳理决定、分歧、待办，继续追问并导出。
- 音频转写：MOSS-Transcribe 1.0 普通转写，或 Diarize-Pro 多说话人转写；可使用本页录音或手动载入录音。
- 会后纪要：Nex N2.6 根据转写整理概要、决定、待办和待确认事项。
- 结论朗读：MOSS-TTS 1.5 Flash / 1.0 Pro，手动生成、播放并下载 MP3。
- 线上会议：Vexa 独立入口，使用自己的 Vexa Key 和会议链接。

## 使用与分享

网页上方显示“公开在线版 · 2026.11.18”，并提供最新 GitHub 源码入口。GitHub 首页优先提供实际在线网址；`cloud/public` 是该在线界面的源码，`public` 是本机界面，`demo` 是明确标注的预设示例。

每位访客填写自己的凭据。分享网址不会带走页面内存中的 Key 或录音。MOSS / Vexa Key 刷新后重新填写；讯飞凭据可以按需仅在当前浏览器加密记住。真实服务仍受各自授权、额度、网络与浏览器麦克风权限约束。

转写和朗读单独计费。Nex N2.6 只输出文字，全双工语音由 MOSS-Live 或讯飞承担。在线版没有在访客电脑上执行 Codex 的权限，本机委派功能使用本机版。
